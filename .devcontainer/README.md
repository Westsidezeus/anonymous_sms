# Codespaces Setup for anonymous_sms

This Codespace automatically installs Python and required dependencies.

## How to Run

1. Open a terminal in your Codespace.
2. Run:

    ```bash
    python sms.py
    ```

3. Follow the prompts in the CLI.

## Notes

- All installs are automatic.
- If you need additional Python modules, use `pip install <module>`.
